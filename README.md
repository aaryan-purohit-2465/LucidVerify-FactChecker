# LucidVerify – Fact Checker

LucidVerify is a full-stack web application that checks whether a given news statement is **real or fake** using intelligent analysis.

## Tech Stack
- Frontend: React (Vite), CSS  
- Backend: FastAPI (Python)

## Features
- Paste news text and verify authenticity
- Confidence score for predictions
- Clean, responsive UI
- REST API backend

## Run Locally

### Backend
py -3 -m uvicorn backend.app.main:app --reload

### Frontend
cd frontend
npm install
npm run dev
