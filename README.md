# LucidVerify — AI Fact Checker

LucidVerify is a full-stack AI-powered fake news detection platform built using FastAPI and React.  
It analyzes news headlines and claims to classify them as **Real** or **Fake** with confidence and explanation.

---

## 🚀 Features
- AI-powered news verification
- Confidence scoring
- Explainable predictions
- Modern animated UI
- Real-time backend API
- Fully deployed product

---

## 🧠 Tech Stack
**Frontend**
- React (Vite)

- Animations & UX

**Backend**
- FastAPI
- AI rule engine
- Confidence scoring
